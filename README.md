# 机器人控制系统 - Linux版本

本项目提供了一个Linux兼容的机器人控制系统，具有全面的传感器集成功能，是从原始Windows版本移植而来的。

## 功能特性

- **Linux兼容的串口通信**：使用POSIX API
- **多线程传感器数据采集**：超声波、红外、罗盘/陀螺仪
- **实时机器人控制**：电机速度控制
- **高级控制功能**：包括基于陀螺仪的导航
- **信号处理**：清洁关闭机制
- **模块化架构**：清晰的关注点分离

## 项目结构

```
robot/
├── base/
│   ├── SerialCom.h         # 串口通信接口
│   ├── SerialCom.cpp       # Linux兼容的串口实现

├── main.cpp               # 集成传感器的主应用程序
├── CMakeLists.txt         # 构建配置
└── README.md             # 本文件
```

## 硬件接口

### 串口通信
- **协议**：带帧验证的自定义二进制协议
- **波特率**：19200（可配置）
- **数据格式**：8N1（8位数据位，无校验，1位停止位）
- **帧结构**：
  ```
  [0x55][0xAA][ADDR][STATUS|LENGTH][CTRL_CODE][DATA...][CHECKSUM]
  ```

### 电机控制
- **左电机**：通过命令0x24控制速度
- **右电机**：通过命令0x25控制速度
- **双电机**：通过命令0x26同时控制
- **刹车**：通过命令0x21紧急停止

### 传感器集成
- **超声波传感器**：24个传感器，命令0x30
- **红外传感器**：24个传感器（3字节），命令0x36
- **罗盘/陀螺仪**：方向数据，命令0x34
- **自动查询**：可配置的轮询间隔

## 构建说明

### 前置条件
- CMake 3.10或更高版本
- C++11兼容的编译器（推荐g++）
- pthread库

### 构建过程
```bash
# 创建构建目录
mkdir build
cd build

# 配置和构建
cmake ..
make

# 运行应用程序
./robot_control
```

## 使用方法

### 基本命令
```
f - 前进
b - 后退  
l - 左转
r - 右转
s - 停止
w - 慢速前进（测试用）
q - 退出
```

### 传感器命令
```
t - 启用传感器（自动查询）
x - 禁用传感器
```

### 高级命令
```
k - 踢球动作
d - 标定（陀螺仪校准）
```

### 传感器数据显示
启用传感器后，系统会自动显示：
- **超声波传感器距离**（米）
- **红外传感器状态**（检测到/未检测）
- **罗盘/陀螺仪方向**数据

## 配置

### 串口配置
编辑`main.cpp`进行配置：
- 串口设备（默认：`/dev/ttyUSB0`）
- 波特率（默认：19200）
- 数据格式（8N1）

### 传感器轮询间隔
在`main.cpp`中修改`AutoQuery*`调用：
```cpp
voyCmd.AutoQueryUSonic(500);      // 500ms间隔
voyCmd.AutoQueryInfraRed(200);    // 200ms间隔  
voyCmd.AutoQueryCompass(1000);    // 1000ms间隔
```

## 技术细节

### 帧协议
- **起始字节**：0x55, 0xAA
- **地址**：设备地址（0x01为电机，0x02为传感器）
- **状态/长度**：状态在位6-7，长度在位0-5
- **控制码**：命令标识符
- **数据**：可变长度载荷
- **校验和**：8位和，初始值0xFF

### 电机速度编码
- **范围**：-30000到+30000
- **方向**：位15表示前进（0）或后退（1）
- **格式**：大端16位值

### 传感器数据格式
- **超声波**：原始字节值转换为米（×0.02174）
- **红外**：位打包的布尔值（3字节=24个传感器）
- **罗盘**：0.1°分辨率的16位角度值

## 故障排除

### 串口问题
- 确保正确的设备路径（`/dev/ttyUSB0`、`/dev/ttyUSB1`等）
- 检查权限（可能需要`sudo`或组成员身份）
- 验证波特率与机器人控制器匹配

### 传感器数据问题
- 检查行为实现中的传感器启用标志
- 验证轮询间隔是否合适
- 监控帧验证错误

### 线程问题
- 确保析构函数中的适当线程清理
- 检查共享数据访问中的竞态条件
- 监控长时间运行操作的内存使用情况
