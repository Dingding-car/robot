# 机器人控制系统

基于Linux平台的机器人控制系统，支持串口通信、传感器数据采集和机器人运动控制。

## 功能特性

- **串口通信**: 支持Linux下的串口通信，兼容USB转串口设备
- **传感器支持**: 
  - 超声波传感器（最多24个）
  - 红外传感器（最多24个）
  - 罗盘/陀螺仪
- **运动控制**: 
  - 双电机独立控制
  - 前进/后退/转向
  - 陀螺仪辅助导航
- **自动查询**: 支持传感器数据的自动轮询

## 系统要求

- Linux操作系统
- C++11编译器
- CMake 3.10+
- 串口设备（如USB转TTL模块）

## 编译和运行

### 编译

```bash
# 创建构建目录
mkdir build
cd build

# 生成Makefile
cmake ..

# 编译
make
```

### 运行

```bash
# 运行程序（需要root权限访问串口）
sudo ./bin/robot_control
```

## 使用说明

### 基本控制命令

- `f` - 前进
- `b` - 后退  
- `l` - 左转
- `r` - 右转
- `w` - 慢速前进（测试用）
- `s` - 停止
- `q` - 退出

### 传感器控制

- `t` - 启用传感器自动查询
- `x` - 禁用传感器自动查询
- `d` - 陀螺仪标定

### 传感器配置

在`VoyCmd.cpp`中可以配置要启用的传感器：

```cpp
// 超声波传感器编号列表
const int usonicEnableList[] = {1, 4, 13, 16, 19, 22};
```

## 代码架构

### 核心类

- **SerialCom**: 串口通信类，负责底层串口操作
- **CVoyCmd**: 机器人指令类，处理传感器数据和运动控制
- **IBehavior**: 行为接口，用于处理传感器数据回调

### 通信协议

使用自定义的串口通信协议：
- 帧头：0x55AA
- 地址：设备地址
- 状态和长度：状态位+长度
- 控制码：命令类型
- 数据：命令数据
- 校验和：8位累加和

## 注意事项

1. 程序需要root权限才能访问串口设备
2. 默认使用/dev/ttyUSB0端口，如需更改请修改main.cpp
3. 传感器数据会自动显示在控制台
4. 使用Ctrl+C可以安全退出程序

## 开发

### 添加新传感器

1. 在`VoyCmd.h`中添加传感器常量
2. 在`CVoyCmd`类中添加相应的数据成员
3. 实现传感器查询方法
4. 在`m_ParseFrame`中添加数据解析逻辑

### 添加新控制命令

1. 在`CVoyCmd`类中添加控制方法
2. 实现命令生成逻辑
3. 在`main.cpp`中添加用户界面支持
